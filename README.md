# Azure AI Text Analytics Sentiment

This Python script demonstrates how to integrate Azure AI Language services, specifically Text Analytics for sentiment analysis. It showcases a core skill covered by the Microsoft AB-650 exam: leveraging AI solutions with potential Microsoft 365 data. The example processes a sample Turkish text, illustrating how AI can extract insights from content that might originate from M365 applications.

## Language

`python`

## How to Run

1. Obtain an Azure AI Language resource key and endpoint from the Azure portal.
2. Set them as environment variables: `AZURE_AI_LANGUAGE_ENDPOINT` and `AZURE_AI_LANGUAGE_KEY`.
3. Run the script: `python main.py`
